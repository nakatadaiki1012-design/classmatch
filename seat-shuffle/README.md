# 🎪 セキガエ・フェス！（エンタメ席替えアプリ）

教室の電子黒板・プロジェクターに映して、クラス全員で盛り上がる席替えWebアプリです。
`index.html` 1ファイルだけで動きます（ダブルクリックでブラウザで開くだけ）。

## 使い方
1. `⚙ 設定` … クラス名・生徒名（1行に1人、名簿を貼り付けOK）・列数×行数・形（通常／ペア／島型）・窓の位置
2. `🔒`（右上の小さい鍵）… **先生用シークレット設定**（投影中は開かないよう注意）
   - 視力配慮：前列固定（前から何行目以内か選べる）
   - 相性配慮：この2人を離す（前後左右・斜めで隣にしない／ペア・島型なら同じ班にもしない）
   - 前回と同じ席にしない
3. 演出モードを選んで `▶ スタート！`（Enter / スペースキーでもOK、実行中は `S` でスキップ）

## 演出モード
| モード | 内容 |
|---|---|
| 💀 サバイバル | 3・2・1のカウントダウン後、1人ずつスロットで確定。「教卓の真ん前」「窓際最後尾（主人公席）」などの注目席はサイレン付きで後半に登場 |
| ⚔️ RPGパーティ | 座る場所で 勇者・前衛ナイト・魔導士・僧侶・アーチャーなどのロールが決まる。ドット絵風UI＋8bitサウンド |
| 🏇 競馬レース | 名前入りの馬が画面中を駆け回り、実況つきで1着から順に席へ滑り込む |
| 🃏 一括オープン | 裏向きカードが配られ、ドラムロール → 一斉／横列ごと／1枚ずつオープン＋紙吹雪 |

スピード（ゆっくり〜爆速）も選べます。

## 席が決まった後のお楽しみ
- **シークレット・ミッション** … 席をタップすると、実際の隣・前・斜め前の人の名前入りアイスブレイクミッションが出ます
- **✨ 席の称号** … 「今日の窓開け担当席」「質問ポイント2倍席」などをランダム付与
- **🎫 席トレード権** … 1〜2名にチケットが当たり、交渉タイマー（1〜5分）が起動。合意したら2つの席をタップで交換
- **🔄 席を入れ替え** … 先生が手動で調整したいとき用
- **📄 座席表を出力** … 印刷（A4横）・PNG画像保存。「先生目線（教卓を下）」にも切り替え可能

## メモ
- 設定は使っているブラウザに自動保存されます。
- 効果音は右上 🔊 でミュートできます。
- フォントと紙吹雪ライブラリはネットから読み込みます（オフラインでも簡易版で動きます）。
