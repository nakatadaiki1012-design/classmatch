# 物理ラボ3D

高校物理（物理基礎・物理）の現象を、**3Dで動かして見る**Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。
見た目と画面の構成は「分子ラボ3D（chemistry-simulator）」とそろえています。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 左の一覧から実験をえらぶ（力学・熱・波・電磁気・原子）
3. 右のパネルのスライダーを動かすと、3Dの実験がその場で変わる
4. 3Dは **ドラッグで回転**、**ホイール／ピンチで拡大**、右ドラッグで平行移動

> 立体表示の部品（three.js）とフォントはインターネットから読み込みます。授業で使うときはネットにつながった状態で開いてください。

## 画面の構成

- 画面上は **実験／計算／クイズ** の3つだけ。
- 3Dの下に **再生・一時停止・コマ送り・はじめから・スロー（×0.1／×¼）** のバー。スペースキーで一時停止、R キーではじめから。
- 右のパネルは「やってみる」「しくみ・公式」「ポイント」の3つのタブ。
  - やってみる：スライダー・切りかえ、測定値（その場で変わる）、グラフ、エネルギーのバー
  - しくみ・公式：現象の説明と公式
  - ポイント：○×でまとめた要点と「テスト・入試に出るポイント」、その単元の計算問題へのボタン
- 各実験に「やってみよう」の課題。達成すると ✓ がつく（ブラウザに保存）。

## 計算（21種類）

数字が毎回変わる計算問題。答えを入れると正解か判定し、解き方を表示します。
「1.2×10^5」「1.2e5」の形でも入力できます。うしろの3Dには、その問題に関係する実験が動いています。

自由落下・投げ上げ・水平投射・斜方投射・斜面の加速度・衝突・ばね振り子・単振り子・向心力・第1宇宙速度・状態方程式・ボイルシャルル・v = fλ・閉管・ドップラー効果・屈折・臨界角・レンズの式・並列回路・磁場中の円運動・光電効果

## クイズ

考え方を確かめる4択問題（37問）。1回10問。分野をえらべます。答えると解説と「実験で確かめる」ボタンが出ます。8問以上で合格のはんこ。

## しくみ（先生向けメモ）

- 運動は、決まった小さな時間ごとに計算しています（運動方程式をそのまま数値計算）。単振り子は sin θ のまま計算するので、振れ角が大きいと周期が公式より長くなります。
- 磁場中の荷電粒子はボリス法で計算しているので、速さが変わりません。
- 気体の分子どうしの衝突は省略しています。圧力は、かべが受けた力積から求めています。
- URLの最後に `#proj` のように付けると、その実験を開いた状態のリンクになります（ID は `index.html` の `sim({ id: ... })`）。

## 見た目

分子ラボ3D と同じ「理科の実験ノート」の見た目。紙の方眼の背景・墨色の文字・明朝体の見出し・緑青（アクセント）と朱（強調）。床は方眼紙（1マス = 1目盛り）。ダークモードは黒板（深緑）の色。
