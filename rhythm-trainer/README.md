# リズム練習アプリ（吹奏楽向け）

吹奏楽の**読譜（リズム）練習**用Webアプリ。2つのモードを相互リンクで行き来できます。

| ファイル | 内容 |
|---|---|
| `index.html` | **リズム譜トレーナー** … 楽譜を読んで叩く（読む→叩く） |
| `recorder.html` | **リズム採譜** … 叩いたリズムが楽譜になる（叩く→書く） |

> **最初に1回だけ「レイテンシーの自動調整」を実行してください。** スマホは音とタッチに 80〜150ms の遅れがあり、調整しないと正しく叩いても Miss になったり、音符が後ろにズレて記譜されます。トレーナーの初回起動時にバナーで案内します（調整値は2つのモードで共通）。

---

## ① リズム譜トレーナー（`index.html`）

リズム譜の上を再生カーソルが進み、音符の位置で **スペースキー / 画面タップ**（演奏中は画面のどこでもOK）。

- **拍をまたぐリズムに対応**：付点四分＋八分（マーチ）、シンコペーション、2拍3連、二分音符・二分休符。パレット下段の「2拍ぶん」から選べます。
- **拍子**：4/4・3/4・2/4・5/4・**6/8（複合拍子）**・**2/2（アラ ブレーヴェ）**。6/8 は1拍＝付点四分として3つ割りで正しく記譜されます。
- **結果に「走り／もたり」**を表示。平均ズレ(ms)、早い/遅いの内訳、目盛り付きバーで傾向が分かります。
- **もう一度**ボタン、**くり返し**（1〜8回）と**1周ごとのテンポアップ**（+5 / +10）。
- **ランダム出題**、**課題の保存**（名前付き）と**共有リンク**（URLを配れば同じ課題を全員で）。
- **練習履歴**：今日のベスト精度と連続日数を表示。
- リズム唱・拍番号の表示切替、判定の厳しさ（やさしい / ふつう / きびしい）、音量・クリック音の選択。
- 演奏中は**画面がスリープしません**（Wake Lock）。タップで軽く振動します。

## ② リズム採譜（`recorder.html`）

叩いたリズムがそのまま楽譜になります。入力方法は3通り。

- **叩いて入力（押した長さ）**：押している時間＝音符、離している時間＝休符。**レガート補正**をONにすると、次の音に間に合うよう早めに離しても付点になりません。
- **音符／休符ボタン（リアルタイム）**：音符を叩くとそこから音が始まり**次のタップまで持続**、休符を叩くと**次に音符を叩くまで休み**。押しっぱなしが不要で一番ラクです。
- **1つずつ置く**：音価を選んで音符・休符を置くステップ入力（キー：N / R / Backspace）。
- **グリッド「自動」**：拍ごとに十六分系か三連符系かを判定するので、**両方が混ざったリズム**も書き分けられます。
- 録音中は叩いた位置がその場で譜面に表示され、あとから**グリッドや設定を変えると録り直さずに再変換**されます。
- **タイミング表示**で、実際に叩いた位置と長さを色分けの帯で確認できます。

## スマホへのインストール（PWA）

ブラウザで開いて「ホーム画面に追加」すると、アイコンから起動でき**オフラインでも動作**します。

## デザイン・浄書について

- 楽譜は**多段レイアウト**。画面幅に合わせて1段あたりの小節数を自動で決めて折り返します（スマホでは1小節/段で大きく読めます）。「1段」表示も選べます。
- **五線スペースを基準単位 U** とした比率設計で、符頭・符幹・連桁・旗・付点・タイ・連符ブラケット・各種休符（全/二分/四分/八分/十六分）をSVGで生成しています。
- 拍子記号は最初の段のみ、終止線は細線＋太線、タイは先細り、二分以上は白抜き符頭——といった記譜の慣習に沿っています。
- エディタや音価パレットのアイコンも同じ描画エンジンで生成した**ミニ楽譜**です。

## 技術メモ

- 単一HTML（外部依存なし）＋ PWA用の `manifest.webmanifest` / `sw.js` / アイコン。
- 音・タイミング：Web Audio API（ルックアヘッド・スケジューリング、`latencyHint:"interactive"`、マスターゲインで音量制御）。
- **入力精度**：タップ時刻は `event.timeStamp` を音声時計に換算して使用し、メインスレッドの遅れによるジッタを排除。さらに8回タップで端末の遅延を実測する自動調整を併用。
- **座標系**：拍→座標を段内で完全な線形にしてあり、音符とカーソルが常に一致して等速で進みます。
- 採譜エンジン：内部分割 12（十六分=3・三連八分=4 の最小公倍数）で、拍ごとに分割系を選んで量子化。
