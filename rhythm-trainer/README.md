# 🥁 リズム譜トレーナー

吹奏楽の**読譜(リズム)練習**用の、カスタマイズ可能な太鼓の達人風Webアプリです。
設定したリズム譜の上を再生カーソルが動き、音符の位置で **スペースキー / タップ** して精度を競います。

## 特徴

- **本物のリズム譜を表示**（四分・八分・十六分・タッカ・三連符・休符）。○記号ではなく実際の音符なので、遊びながら読譜力が身につきます。
- **拍ごとにパターンを選ぶだけ**の簡単エディタ。指導者が課題リズムを自由に設定できます。
- テンポ(BPM)・拍子(2/4・3/4・4/4)・カウントイン・小節数を調整可能。
- **リズム唱**（タン／タタ／タカタカ…）表示と**お手本音**で、音とリズムの結びつきを補助。
- **Perfect / Good / Miss** 判定、コンボ、総合精度%。Web Audio API による正確なメトロノーム。
- 依存ライブラリなしの**単一HTMLファイル**。オフラインでも動作します。

## 使い方

1. `index.html` をブラウザ（PC・スマホ・タブレット）で開く。
2. 「課題リズムの設定」で各拍をタップし、リズムパターンを選ぶ（プリセットからも読込可）。
3. まず **🎧 お手本を聴く** で正しいリズムを耳で確認。
4. **▶ スタート** → カウントインのあと、音符の位置で **スペースキー / 画面タップ**。
5. 終了後に精度・コンボ・アドバイスが表示されます。

## 練習のコツ

- 最初はテンポを落とし、リズム唱を声に出しながら叩くと定着しやすいです。
- 休符（ウン）の拍は叩きません。カーソルが通過してもタップ不要です。
- 慣れてきたらテンポを上げる／難しいパターン（タッカ・十六分・三連符）に挑戦。

## 技術メモ

- 単一の `index.html`（HTML + CSS + JavaScript、外部依存なし）。
- 音・タイミング：Web Audio API（`AudioContext.currentTime` によるルックアヘッド・スケジューリング）。
- 楽譜描画：SVG で符頭・符幹・連桁・休符・拍子記号を動的生成。
- スマホ対応：`pointerdown` によるタップ入力、レスポンシブUI。
