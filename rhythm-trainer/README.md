# 🥁 リズム練習アプリ（吹奏楽向け）

吹奏楽の**読譜(リズム)練習**用Webアプリ。2つのモードを相互リンクで行き来できます。

| ファイル | 内容 |
|---|---|
| `index.html` | **リズム譜トレーナー** … 楽譜を読んで叩く（読む→叩く） |
| `recorder.html` | **リズム採譜** … 叩いたリズムが楽譜になる（叩く→書く） |

---

## ① リズム譜トレーナー（`index.html`）

設定したリズム譜の上を再生カーソルが動き、音符の位置で **スペースキー / タップ** して精度を競います。

## 特徴

- **本物のリズム譜を表示**（四分・八分・十六分・タッカ・三連符・休符）。○記号ではなく実際の音符なので、遊びながら読譜力が身につきます。
- **拍ごとにパターンを選ぶだけ**の簡単エディタ。指導者が課題リズムを自由に設定できます。
- テンポ(BPM)・拍子(2/4・3/4・4/4)・カウントイン・小節数を調整可能。
- **リズム唱**（タン／タタ／タカタカ…）表示と**お手本音**で、音とリズムの結びつきを補助。
- **Perfect / Good / Miss** 判定、コンボ、総合精度%。Web Audio API による正確なメトロノーム。
- 依存ライブラリなしの**単一HTMLファイル**。オフラインでも動作します。

## 使い方

1. `index.html` をブラウザ（PC・スマホ・タブレット）で開く。
2. 「課題リズムの設定」で各拍をタップし、リズムパターンを選ぶ（プリセットからも読込可）。
3. まず **🎧 お手本を聴く** で正しいリズムを耳で確認。
4. **▶ スタート** → カウントインのあと、音符の位置で **スペースキー / 画面タップ**。
5. 終了後に精度・コンボ・アドバイスが表示されます。

## 練習のコツ

- 最初はテンポを落とし、リズム唱を声に出しながら叩くと定着しやすいです。
- 休符（ウン）の拍は叩きません。カーソルが通過してもタップ不要です。
- 慣れてきたらテンポを上げる／難しいパターン（タッカ・十六分・三連符）に挑戦。

## ② リズム採譜（`recorder.html`）

叩いたリズムがそのまま楽譜になります（リズム聴音・ディクテーションの逆再生）。
「読む」の逆で、**自分が叩いた長さ → どう書くか** を結びつけ、読譜力を別角度から鍛えます。

### 使い方

1. テンポ・拍子・録音小節数・グリッド・変換モードを設定。
2. **● 録音スタート** → カウントインのあと、メトロノームに合わせて叩く。
3. 設定小節数ぶんで自動停止し、**楽譜に変換**。**▶ 変換結果を再生**で確認。

### 入力方法

- **叩いて入力（リアルタイム）**：メトロノームに合わせて叩き、タイミングから採譜します。
- **ボタンで入力（音符／休符）**：音符ボタンと休符ボタンで1つずつ置いてリズムを組み立てるステップ入力。**休符も自分で入力**するので、休符の読み書き練習に最適。タイミング判定がないため誤変換がありません（キー：N=音符 / R=休符 / Backspace=戻る）。

### 変換モード（リアルタイム時）

- **実際の長さ**：押している時間＝音符の長さ、離している時間＝休符。四分音符ぶんは1拍押し続けます。
- **叩いた間隔**：叩いた瞬間だけを見て次の音まで伸ばす（休符なし・スタッカートでもOK）。初心者はこちらが簡単。
- **レガート補正**：次の音までほぼ押していれば、早めに離してもその音価に丸めます（付点化・不要なすき間を防止）。

### しくみ

- タップの押下/離しの時刻を記録 → 8分 or 16分グリッドに量子化 → 音符・休符に変換。
- 拍をまたぐ長い音は**タイ**で連結、拍ごとに**連桁**、休符も自動配置。

---

## 技術メモ

- 各ページとも単一HTML（HTML + CSS + JavaScript、**外部依存なし**）。オフライン動作。
- 音・タイミング：Web Audio API（`AudioContext.currentTime` によるルックアヘッド・スケジューリング）。
- 楽譜描画：SVG で符頭・符幹・連桁・付点・タイ・休符・拍子記号を動的生成。採譜側は独自の簡易採譜エンジンで量子化。
- スマホ対応：`pointerdown`/`pointerup` によるタップ入力、レスポンシブUI。
