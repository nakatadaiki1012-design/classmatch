# 🥁 リズム練習アプリ（吹奏楽向け）

吹奏楽の**読譜(リズム)練習**用Webアプリ。2つのモードを相互リンクで行き来できます。

| ファイル | 内容 |
|---|---|
| `index.html` | **リズム譜トレーナー** … 楽譜を読んで叩く（読む→叩く） |
| `recorder.html` | **リズム採譜** … 叩いたリズムが楽譜になる（叩く→書く） |

---

## ① リズム譜トレーナー（`index.html`）

設定したリズム譜の上を再生カーソルが動き、音符の位置で **スペースキー / タップ** して精度を競います。

## 特徴

- **本物のリズム譜を表示**（四分・八分・十六分・タッカ・三連符・休符）。○記号ではなく実際の音符なので、遊びながら読譜力が身につきます。
- **拍ごとにパターンを選ぶだけ**の簡単エディタ。指導者が課題リズムを自由に設定できます。
- テンポ(BPM)・拍子(2/4・3/4・4/4)・カウントイン・小節数を調整可能。
- **リズム唱**（タン／タタ／タカタカ…）表示と**お手本音**で、音とリズムの結びつきを補助。
- **Perfect / Good / Miss** 判定、コンボ、総合精度%。Web Audio API による正確なメトロノーム。
- 依存ライブラリなしの**単一HTMLファイル**。オフラインでも動作します。

## 使い方

1. `index.html` をブラウザ（PC・スマホ・タブレット）で開く。
2. 「課題リズムの設定」で各拍をタップし、リズムパターンを選ぶ（プリセットからも読込可）。
3. まず **🎧 お手本を聴く** で正しいリズムを耳で確認。
4. **▶ スタート** → カウントインのあと、音符の位置で **スペースキー / 画面タップ**。
5. 終了後に精度・コンボ・アドバイスが表示されます。

## 練習のコツ

- 最初はテンポを落とし、リズム唱を声に出しながら叩くと定着しやすいです。
- 休符（ウン）の拍は叩きません。カーソルが通過してもタップ不要です。
- 慣れてきたらテンポを上げる／難しいパターン（タッカ・十六分・三連符）に挑戦。

## ② リズム採譜（`recorder.html`）

叩いたリズムがそのまま楽譜になります（リズム聴音・ディクテーションの逆再生）。
「読む」の逆で、**自分が叩いた長さ → どう書くか** を結びつけ、読譜力を別角度から鍛えます。

### 使い方

1. **最初に1回だけ**「詳細設定 → レイテンシーを自動調整」を実行します（重要）。
2. テンポ・拍子・小節数・グリッド・入力方法を設定。
3. **● 録音スタート** → カウントインのあと、メトロノームに合わせて叩く。
4. 設定小節数ぶんで自動停止し、**楽譜に変換**。**再生**で確認。

> **レイテンシー調整をしないと音符が後ろにズレます。** 端末の音声出力とタッチには遅れがあり（スマホでは 80〜150ms、Bluetooth接続だとさらに大きい）、その分タップが遅れて記録されます。例えば ♩=180 で 85ms 遅れると、ちょうど十六分音符1つぶん後ろに書かれます。調整値はトレーナーと共通で、ブラウザに保存されます。

### 入力方法（3種類）

- **叩いて入力（押した長さ）**：押している時間＝音符、離している時間＝休符。**レガート補正**をONにすると、次の音に間に合うよう早めに離しても付点になりません。
- **音符／休符ボタン（リアルタイム）**：メトロノームに合わせ、音符ボタンを叩くとそこから音が始まり**次のタップまで持続**。休符ボタンを叩くと**次に音符を叩くまで休み**。押しっぱなしが不要で一番ラクかつ正確です。
- **ボタンで入力（1つずつ置く）**：リアルタイムではなく音価を選んで音符・休符を置くステップ入力。記譜の練習向け（キー：N=音符 / R=休符 / Backspace=戻る）。

### グリッド（十六分と三連符の両対応）

- **自動（十六分＋三連）**：拍ごとに十六分系か三連符系かを量子化誤差から判定するので、**両方が混ざったリズム**も1小節内で書き分けられます。
- 固定モード（十六分のみ／八分のみ／三連符のみ）も選べます。
- グリッドや変換設定を変えると、**録り直さずに同じ演奏を再変換**します。

### しくみ

- タップの押下/離しの時刻を記録 → 8分 or 16分グリッドに量子化 → 音符・休符に変換。
- 拍をまたぐ長い音は**タイ**で連結、拍ごとに**連桁**、休符も自動配置。

## デザイン・浄書について

- 楽譜は**多段レイアウト**。画面幅に合わせて1段あたりの小節数を自動で決め、折り返します（スマホでは1小節/段になり、縮小せず大きく読めます）。「1段」表示に切り替えると全体を1行で見られます。
- 描画は**五線スペースを基準単位 U** とした比率設計で、符頭・符幹・連桁・旗・付点・タイ・三連符ブラケット・各種休符をすべて浄書の比率に合わせてSVGで生成しています。
- 拍子記号は最初の段のみ、終止線は細線＋太線、タイは先細り——といった記譜の慣習に沿っています。
- エディタや音価パレットのアイコンも同じ描画エンジンで生成した**ミニ楽譜**です。

## 技術メモ

- 各ページとも単一HTML（HTML + CSS + JavaScript、**外部依存なし**）。オフライン動作。
- 音・タイミング：Web Audio API（`AudioContext.currentTime` によるルックアヘッド・スケジューリング、`latencyHint:"interactive"`）。
- **入力精度**：タップ時刻は `event.timeStamp` を音声時計に換算して使用し、メインスレッドの遅れによるジッタを排除。加えて端末の出力遅延を測る自動キャリブレーション（判定オフセット）を併用。
- **座標系**：時間→X座標を単一の線形式にしてあり、音符の位置と再生カーソルが常に一致し**等速**で動きます（カーソルは `transform` で描画）。
- **表示**：「全体表示」は画面幅に収まるよう自動縮小（拡大はしない）、「拡大」は原寸＋横スクロール。スマホでは配置を自動でコンパクト化。
- 楽譜描画：SVG で符頭・符幹・連桁・付点・タイ・三連符ブラケット・各種休符（全/二分/四分/八分/十六分）を動的生成。
- 採譜エンジン：内部分割 12（十六分=3・三連八分=4 の最小公倍数）で、拍ごとに分割系を選んで量子化。
- スマホ対応：`pointerdown`/`pointerup` によるタップ入力、レスポンシブUI。
