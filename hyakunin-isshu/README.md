# 🎴 百人一首 道場（練習アプリ）

本物のかるたで練習しているような**リアルな札**と、**音声の読み上げ**で百人一首を練習できるWebアプリです。
`index.html` をブラウザ（スマホ・タブレット・PC）で開くだけで使えます。インストール不要。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `data.js` | 百人一首100首のデータ（漢字・歴史的かなづかい・読み上げ用のかな） |

## 3つのレベル

### 🟢 初心者「覚える」
- **暗記カード**：読み札（上の句）を音声で聞き、取り札をめくって下の句を確認。「○覚えた／×まだ」で記録されます。
- **4択で取る**：上の句を聞いて、4枚の取り札から正しい札を選ぶクイズ（10問）。「似た札をまぜる」で難しくできます。
- **声で答える**：上の句を聞いたら、下の句を**声に出して**答える。マイクで聞き取って自動で判定します（Chrome・Safari・Edge）。
- **一覧**：100首を一覧表示。決まり字が赤字で分かります。

### 🟡 中級者「取る」
- 畳の上に取り札（8〜25枚）を並べ、読み上げを聞いて正しい札をタップ。
- 違う札にさわると**お手つき**。「空札あり」にすると、場にない歌も読まれます（本番と同じ）。
- 読んでいる文字を画面に出す／出さないを選べます。

### 🔴 上級者「早く取る」
- 25枚または50枚。**相手陣は逆さ**に並ぶ本番形式。序歌（なにわづに…）から始まります。
- 取った時間に加えて、**決まり字が読まれてから何秒で取れたか**を記録。目標は「決まり字を聞いた瞬間」。
- 読まれた歌が増えると決まり字が短くなる**決まり字の変化**にも対応（ヒント表示で確認できます）。
- 平均時間の**自己ベスト**を保存。

## 本物らしさのこだわり
- 取り札は**ひらがなの下の句だけ**を縦書き3列、緑のふち付き。設定で「本物風（濁点なし・『ゝ』を使う）」と「わかりやすく（濁点あり）」を切り替えられます。
- 読み札は漢字の歌と作者名入り。
- 書体は明朝／毛筆風を選べます。

## 設定（⚙）
- 練習する範囲：全100首／20首ずつ／1字決まり・2字決まり…／まだ覚えていない歌
- 音声のオン・オフ、声の種類、読む速さ（ゆっくり・ふつう・試合くらい）

## 注意
- 音声はブラウザに入っている日本語の声を使います。端末によって声や読み方が少し違います。iPhoneは消音スイッチをオフにしてください。
- 画面に出る文字と音声のタイミングは目安です。
- 覚えた記録・設定は、その端末のブラウザに保存されます。
