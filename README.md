# 吹奏楽チューナー（Band Tuner）

吹奏楽部でスマホを使ってピッチを合わせるための Web アプリです。
インストール不要で、スマホのブラウザを開くだけで使えます。Bluetooth スピーカーを
つないでいれば、音はそのままスピーカーから出るので、全員でピッチ合わせができます。

## できること

### 🎵 音出し（ドローン）
- **基準ピッチ**を A=440 / 442 / 443 Hz からワンタッチで選択（＋/− で 430〜446 Hz まで微調整可）
- 好きな音（実音）を選んで、伸ばした音（ドローン）を鳴らしっぱなしにできます
- その音に自分の楽器を合わせて練習できます
- 音色は「リッチ（倍音あり＝合わせやすい）」「サイン（純音）」などから選択
- 音名は **実音** と **B♭管での読み替え** を両方表示

### 🎯 チューナー
- スマホのマイクで音を拾い、**音名**と**基準からのズレ（セント）**を針で表示
- 針が真ん中（緑）でピッタリ。左に振れたら低い、右なら高い
- 基準ピッチ（A=442 など）は上のバーの設定と連動します

### 🎼 ハーモニー（純正律）
- 和音のルートとコードの種類（メジャー / マイナー / 7th / sus4 など）を選んで和音を再生
- **平均律 ⇄ 純正律**を切り替え可能
- 純正律では第3音を低め・第5音をわずかに高めにして、**うなりの無いハーモニー**になります
- 各音が平均律から何セントずれているかをバーで表示するので、合奏でどの音をどれだけ寄せればいいか感覚をつかめます

## 使い方

1. `index.html` をスマホのブラウザで開く（下記「公開方法」参照）
2. 上部で基準ピッチ（442 など）を選ぶ
3. タブを切り替えて「音出し」「チューナー」「ハーモニー」を使う
4. Bluetooth スピーカーをスマホにつなげば、音はスピーカーから出ます

> チューナーはマイクを使うため、初回にマイクの使用許可を求められます。
> iPhone / Android とも、マイクを使う機能は **HTTPS**（または `localhost`）でのみ動作します。

## 公開方法（部員に配る）

このアプリは**サーバー不要の静的ファイル**なので、次のいずれかで公開できます。

- **GitHub Pages**：このリポジトリの Settings → Pages で公開ブランチを指定するだけ。
  公開された URL を QR コードにして配れば、部員は読み取るだけで使えます。
- ローカル確認：`python3 -m http.server` で簡易サーバーを立てて `http://localhost:8000/` を開く。

## 技術メモ

- 依存ライブラリなし。`index.html` 1 ファイルで完結（Web Audio API + getUserMedia）
- 音の生成はオシレータ、チューナーのピッチ検出は自己相関（autocorrelation）法
- `manifest.json` により「ホーム画面に追加」でアプリのように起動できます
