🎶 はじめてのガムラン教室

聴いて、叩いて、しくみがわかる。インドネシアの青銅の合奏音楽「ガムラン」を、レッスンで順番に学び、合奏の中で練習できます。

はじめての人は1から順番にどうぞ。各レッスンの「やってみよう」をクリアすると ✓ がつきます。 クリア 0 / 0

楽器を選ぶと、その楽器の役割・決まりごと（セオリー）・楽譜の例が出ます。「お手本」で聴いて、「一緒に弾く」で合奏の中に入って練習できます。

楽器の音の高さ地図

右へ行くほど高い音。縦の線は「1」の音（1オクターブごと）です。同じ旋律を、楽器ごとにちがうオクターブで鳴らしているのがわかります。点をタップすると音が鳴ります。

伴奏に合わせて自由に弾けます。ゴングの周期を感じながら即興してみよう。

複数の指で同時に叩けます。サロン類は本物と同じく、次の音を叩くと前の音を手で押さえて止めます（ダンプ）。

ゴンガン（ゴングの周期）

針が1周すると最後の拍でゴングが鳴り、また上から始まります。扇形1つ＝ガトラ（4拍）、点線＝クノンの区切り、太線＝ゴング。中央の数字はいまの拍、🔔はゴングまでの残りの拍数です。点をタップするとその拍の役割が出ます。

横が時間、縦が楽器です。上の飾りの楽器ほど細かく、下のゴングほどゆっくり鳴ります。白い線がいまの位置で、鳴った音が光ります。

✏️ 自分で曲を書く

数字＝音、.＝休み。低い音は数字の後に ,（例 6,）、高い音は '（例 1'）。4音で1まとまり（ガトラ）。最後の音がゴングの音になります。

※ 音は Web Audio による合成音です。収録曲は仕組みを学ぶための練習用オリジナル旋律で、装飾パターンは実際の奏法を簡単にしたものです。
