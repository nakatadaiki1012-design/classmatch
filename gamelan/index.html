🎶 ガムラン・シミュレーター

インドネシアの青銅の合奏音楽「ガムラン」を、順番に学んで、叩いて、合奏できます。

はじめての人は1から順番にどうぞ。各レッスンの「やってみよう」をクリアすると ✓ がつきます。 クリア 0 / 0

楽器を選ぶと、その楽器の役割・決まりごと（セオリー）・楽譜の例が出ます。「お手本」で聴いて、「一緒に弾く」で合奏の中に入って練習できます。

複数の指で同時に叩けます。サロン類は本物と同じく、次の音を叩くと前の音を手で押さえて止めます（ダンプ）。

停止中 周回 0 拍 - いまのテンポ -

ゴンガン（ゴングの周期）

G ゴング N クノン P クンプル t クトゥッ

時計のように一周すると最後にゴングが鳴り、また最初へ戻ります。ガムランの曲はこの「ぐるぐる回る時間」で組み立てられています。

✏️ 自分で曲を書く

数字＝音、.＝休み。低い音は数字の後に ,（例 6,）、高い音は '（例 1'）。4音で1まとまり（ガトラ）。最後の音がゴングの音になります。

※ 音は Web Audio による合成音です。収録曲は仕組みを学ぶための練習用オリジナル旋律で、装飾パターンは実際の奏法を簡単にしたものです。
