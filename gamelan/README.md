# 🎶 はじめてのガムラン教室

**聴いて、叩いて、しくみがわかる。** インドネシアの合奏音楽「ガムラン」を、スマホ・タブレット・PCのブラウザで、14ステップのレッスンで順番に学び、楽器ごとの決まりごとを知り、合奏の中で叩いて練習できる学習用Webアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要・オフライン可）。

## 4つのタブ

| タブ | できること |
|---|---|
| 🎓 レッスン | 初心者向けに13ステップで順番に学ぶ。各レッスンは「説明 → ポイント → やってみよう」。聴く・順番に叩く・クイズ・楽譜を見る・合奏の中で弾く（タイミング判定つき）でクリアしていく。進み具合はブラウザに保存。 |
| 🎼 セオリー | 楽器ごとの役割・音域・1拍の音数・道具、決まりごと（セオリー）、コツを解説。楽譜の例を見て、「お手本を聴く」「一緒に弾く」で、ほかの楽器が自動で鳴る合奏の中で練習できる。 |
| 🥢 自由演奏 | サロン／デムン／ペキン／スレンテム／ボナン／ゴング類／クンダン／バリのガンサを画面で叩ける。マルチタッチ対応。 |
| ▶ 自動演奏 | 練習曲を全楽器で自動演奏。ゴングの周期を円で表示、楽器ごとにON/OFF、テンポ・イラマ切替、ブカ（前奏）〜スウック（終わり）。自作曲の入力・おまかせ作曲も可能。 |

### レッスンの順番

1. ガムランってなに？ 2. 音の名前は「数字」 3. 叩いたら止める（ダンプ） 4. 1拍に1音：バルンガン 5. ゴングが時間を区切る
6. クノン・クンプル・クトゥッ 7. ペキン：2回ずつ、先取りで 8. ボナン：2つの音を行ったり来たり 9. 密度の層を重ねる
10. イラマ：遅くなると細かくなる 11. クンダン：太鼓が指揮者 12. バリ：2人でかみ合わせる（コテカン） 13. 卒業：合奏に入ろう 14. おさらいテスト

## 再現している演奏の仕組み

- **音階（ララス）**：スレンドロ（ほぼ等間隔の5音）とペロッグ（7音）。西洋の平均律とは違う音程。
- **コロトミー構造**：ランチャラン（16拍）・クタワン（16拍）・ラドラン（32拍）で、ゴン・アグン／クノン／クンプル／クトゥッ／クンピャンが決まった拍で鳴る。
- **密度の層**：バルンガン（1拍1音）に対し、ペキン・ボナンは2倍、ボナン・パネルスは4倍の細かさで旋律を先取りして装飾。
- **イラマ**：イラマIIに切り替えるとテンポが半分になり、装飾楽器の音数が2倍に。
- **ブカとスウック**：前奏→ゴングで全員が入る→「終わる」で減速してゴングで終止。
- **ダンプ奏法**：サロン類は次の音を叩くと前の音を止める。
- **バリ風**：ポロスとサンシが交互にかみ合う**コテカン**、2台1組の調律差による**オンバ（うなり）**。

## 楽器の形

- セオリー・自由演奏・レッスンに、実物の形をもとにした楽器のイラスト（部位の名前つき）と、合奏の並び方の図を表示。
- 各楽器に「本物の写真を見る」リンク（Wikimedia Commons の画像検索）をつけている。

## 専門的な正確さのために直したこと

- ペロッグの曲を1つのパテット（バラン：2 3 5 6 7）にそろえた（同じ曲で1と7を混ぜない）。パテットの説明を追加。
- イラマを「I（タングン）」「II（ダドス）」と表記し、5段階（ランチャル〜ランケップ）を説明。
- バリ風の曲ではゴング類をバリの名前（クンプール・クモン・カジャール）で表示し、イラマ切替を無効に。
- 用語を追加：ミテット（ダンプ）、ウェラ、クンダン・カリ、ゴン・スウカン、プマデ／カンティラン、プンゴンバン／プンギセップ。

## 周期のガイドと見える化

- **ゴング時計**：周期を時計で表示。扇形＝ガトラ、点線＝クノンの区切り、太線＝ゴング。針はなめらかに回り、中央に「いまの拍」と「ゴングまでの残り拍数」。点をタップするとその拍の役割を説明。
- **いまのガトラ**：4拍を大きく表示し、4拍目（着地点・セレ）を強調。
- **ガイド**：ブカ・1拍目・クノン・クンプル・ウェラ・「もうすぐゴング」・ゴンなどの瞬間に、何が起きているかを文章で表示。
- **全楽器タイムライン**：横＝時間、縦＝楽器。細かさの違い（密度の層）が一目でわかり、鳴った音が光る。
- **音の高さ地図**：楽器ごとの音域を並べて表示（セオリータブ）。
- 練習中は「拍・ガトラ・ゴングまで」を常に表示。レッスン5・6にゴング時計、9・10にタイムラインを追加。

## 音色の検証

ブラウザ内で各楽器の音をオフライン録音して測定し、音程（全楽器で誤差6セント以内）・響きの長さ・音量バランス・合奏時の音割れを確認。
響きが実物より2〜3倍短かったため延長（例：サロン −40dBまで約3.4秒、ゴン・アグン約9秒）、クンピャンの音程（音階外になっていた）とクトゥッのオクターブを修正。

## 使いやすさの工夫

- **タイミングのずれ調整**：練習画面の「⏱ ずれ調整」で、カチッという音に合わせて叩くと、イヤホンや機種による音の遅れを測って判定に反映（ブラウザに保存）。
- **練習**：まちがえた音を叩くと正しい鍵盤を一瞬表示。「合格したら少しずつ速く」でテンポが自動で上がる。
- **自動演奏**：「速く（セセッ）」「ゆっくり」ボタンで、クンダンの合図のようにだんだんテンポが変わる。
- **自由演奏の伴奏**：ゴングと太鼓の伴奏に合わせて即興できる（小さなゴング時計つき）。
- **PCのキーボード**：数字1〜7＝音（Shiftで高い音）、スペース＝ゴング類、D T P K L＝クンダン。
- 演奏中は画面が消えないようにする／自作の曲を次回も復元／音が重なりすぎたら自動で軽量化／タップ時の軽い振動（対応機種）。

## 本物らしさのための追加

- **イラマ変更の流れ**：クンダンが細かく打ち込んで合図 → 全員がだんだんテンポを変える → 次のクノン（区切り）の拍で飾りの細かさがそろって切り替わる。ガイドにも表示。
- **柔らかい楽器**：グンデル（音をめぐって着地）、ルバブ（旋律を少し先取りしてのばし、すべるようにつなぐ）、スリン（クノンやゴングの前で歌う）を簡略化して合成。速く大きな音のランチャランではお休み、クタワン・ラドランで演奏。自由演奏でも弾ける。
- **おさらいテスト**（レッスン14）：16問から毎回10問（音を聴いて答える問題つき）。8問正解で合格。

## ジャワとバリのちがい・直観的な見せ方

- **曲を11曲に**：ジャワ6曲（ランチャラン・クタワン・ラドラン、スレンドロ／ペロッグ、1拍おきの「ニバニ」）、バリ3曲（32拍の曲も）、そして**同じ旋律をジャワ風・バリ風で演奏する比較用2曲**。曲の選択は地域ごとにまとめて表示。
- **バリらしさ**：周の後半ほど強くなる強弱と、クンダンの合図で全員が強く打ってピタッと止まる「アンセル」。
- **ジャワとバリをくらべる**：雰囲気・速さ・飾り方・調律・強弱・音階・楽器の比較表と、聴きくらべボタン（自動演奏タブ、レッスン12）。
- **合奏ステージ**：上から見た楽器の並び（ジャワ／バリで切り替わる）で、鳴った楽器が光る。どの楽器がゆっくりで、どれが細かいかが一目でわかる（自動演奏タブ、レッスン1・12）。
- 楽器の見た目は、なめらかに磨かれた青銅の光沢で表現。

## 自分で曲を書く書式

- 数字＝音、`.`＝休み、`6,`＝低い6、`1'`＝高い1。4音で1ガトラ。最後の音がゴングの音。
- 例：`2 1 2 6,  2 1 2 6,  3 5 6 5  3 2 1 6,`

## 注意

- 音は Web Audio API による合成音です（実際の楽器の録音ではありません）。スマホのスピーカーでは大ゴングの低音は聞こえにくいので、イヤホン推奨。
- iPhone はマナーモード（消音スイッチ）だと音が出ないことがあります。
- 収録曲は仕組みを学ぶための**練習用オリジナル旋律**です。装飾パターン（ミピル、コテカン、太鼓の手）は実際の奏法を簡略化しています。調律も楽団ごとに異なるため代表的な値を使っています。

## 技術メモ

- 単一HTML（外部依存なし）。全楽器のパートは、バルンガン（骨組みの旋律）から「セオリー」に従って自動生成（`derive()`）。自動演奏・レッスン・セオリーの楽譜と練習はすべてこの同じ仕組みを使う。
- 音色：部分音の加算合成に、打撃音（雑音成分）、ゴングの叩いた瞬間の音程の揺れ、倍音のふくらみ、2台1組のうなり、楽器ごとの左右配置、初期反射つきの残響、わずかな人間らしいタイミング・強弱の揺れを加えている。
- 練習の判定：音の出力の遅れ（レイテンシー）を考慮し、拍との時間差で「ぴったり／おしい／ミス」。`AudioContext.currentTime` を使ったルックアヘッド・スケジューラで、1拍を8分割したティック単位で全楽器を正確に発音。
- 楽器音は非整数倍音（鍵盤）や、わずかにずらした部分音（ゴングのうなり）を重ねた加算合成＋簡易リバーブ。
- `pointerdown` によるマルチタッチ入力、レスポンシブUI。

## 演奏セオリーの検証（2026年10月）

ゴングの配置（ランチャラン・クタワン・ラドラン）、ウェラ、ペキン・ボナン・パネルスの奏法、イラマの音数、楽器ごとのオクターブ、音階とパテット、バリのコテカンとオンバを、中部ジャワとバリの標準的な奏法と照らし合わせました。次の点を直しました。

- クンダンの両面同時の音の名前を「ドラン」から「ダン（dhang）」に。ゴングの拍の手もダンにしました。
- スレンドロのクンピャンの音を、高い「1」に（ペロッグは高い「6」のまま）。
- クトゥッの説明を修正（クタワン・ラドランではクンピャンのほうが細かく刻む）。
- パテットの説明の「ブム系」を「パテット・リモやヌム」に統一。
- おさらいテストの問題数の表記（16問→17問）。

## 合奏ページ（最初に開くページ）

アプリを開くと、まず「🥢 合奏」ページが出ます。

1. 演奏したい楽器をえらぶ（ジャワの曲ならサロン・ボナン・ゴングなど11種類、バリの曲ならガンサ・チャルンなど7種類）
2. 曲をえらぶ
3. 「一緒に弾く」を押す → 自分の楽器以外はすべて自動で演奏され、光る音を叩くと「ぴったり／おしい／ミス」を判定

楽器はページの上のほうに出るので、スクロールしなくてもすぐ叩けます。テンポは楽器に合わせて、最初はゆっくりにしてあります。

### 合奏ページの選び方（絵とカード）

- 楽器は、実際に叩く画面と同じ絵のカードから選べます（選んだ楽器に「✓ えらび中」）。
- 曲はカードで横に並び、地域（ジャワ／バリ）、形式、1周の拍数、音階、速さ、むずかしさ（★）、ひとことの説明、1周の中でゴングやクノンが鳴る位置の図が出ます。「▶ 聴いてみる」で試聴できます。

### 叩くタイミングのガイド

- 鍵盤の上に「タイミングのレーン」があり、自分が叩く音が右から流れてきます。左の緑の線に重なった瞬間が叩くタイミングです。拍の線（4拍ごとに太く、ゴングの拍は赤）とカウント（4・3・2・1）も流れます。
- 左はしに「つぎ」に叩く音を大きく表示し、「あと◯拍」「いま！」を出します。
- 次に叩く鍵盤は2拍前から光り、緑の輪が叩く瞬間に向かって縮みます（ぴったり重なったときが叩くタイミング）。
- 叩くと「ぴったり！／おしい／ミス／ちがう音」がレーンに出ます。
- 表示は音が耳に届く時刻（ずれ調整の値）に合わせています。

## 演奏の検証（自動チェック）

全11曲・イラマI／IIで、実際に生成される演奏を1音ずつ取り出し、次の決まりを自動で確認しました（すべて合格）。

- ゴングは1周の最後の拍だけ。クノン・クンプル・クトゥッ・クンピャンの拍がランチャラン／クタワン／ラドランの決まりどおり（ウェラも含む）。
- クノン・クンプルの音の高さが、その拍のバルンガンの音と一致。
- サロンは1拍1音で、休み（.）は鳴らさない。鍵盤の範囲内。
- ペキンは2拍ごとに「x x y y」（イラマIIは「x x y y x x y y」）で、最後の音がバルンガンと同時。
- ボナンは組の最後がバルンガンの音に着地。パネルスはボナンの2倍の細かさ。
- 音階にない音を使わない（ペロッグのバランの曲などを含む）。
- バリ：ポロスとサンシを合わせると1拍4音で、すき間も重なりもない（アンセルの止めを除く）。ポロスは拍の上でポコッの音に着地。カジャールは毎拍、ジェゴガンは2拍に1音。

自動演奏の流れで直したところ：

- ブカ（前奏）の最後のゴングで、全員がそろって入るように（以前はゴングとボナンだけだった）。
- スウック（終わり）は、最後のガトラでしっかり遅くなってからゴングで終わるように（ジャワは約6割の速さまで、バリは控えめ）。最後のガトラの途中で押したときは、次の周で終わる。
- イラマの切り替えは、合図から1ガトラ以上先のクノンで行い、そのときテンポがほぼ半分になっているように（飾りの「流れの速さ」が保たれる）。

### ボナンの弾き方を本物に近づけた（2026年10月）

- ランチャラン（速い曲）では、ミピルではなく「グンビャン」：次の音のオクターブ（高い音と低い音を同時）を裏拍で打ち、バルンガンとは重ねない。パネルスはその間を倍の細かさでオクターブ打ち。
- 同じ音が続く・休みで音がのびるところ（ガントゥンガン）では、行き来せずにオクターブで打つ。
- 練習では、オクターブの音は高い方・低い方どちらの壺を叩いても正解（音は両方鳴る）。楽譜では紫の枠、レーンでは上下の点と「8va」で表示。
- ボナンのレッスンとセオリーの例は、ミピルがよくわかるラドラン「ゆるやかな川」に変更。

## 音のビリビリ（処理落ち）対策

たくさんの音が重なると、スマホの計算が追いつかず音がビリビリすることがありました。次のように軽くしました（同じ曲を12秒鳴らす計算の重さ：約0.45〜0.56 → 約0.04、およそ12〜14分の1）。

- **音の作り置き**：同じ楽器・同じ高さの音は最初の1回だけ合成して録音しておき、2回目からはそれを再生する。曲を選んだとき・練習を開く時に、その曲で使う音を前もって作っておく（音そのものは合成したものと同じ）。
- 標本化を 32kHz、音の受け渡しを少し大きめ（balanced）にして計算と途切れを減らす。
- 聞こえないほど小さくなった余韻は止める。うなり用の2台目の音は軽い作りにする。
- 楽器ごとに同時に響かせる数に上限をつけ、古い響きはそっと消す。
- それでも重いときは、弱い倍音や雑音成分を自動で省く。
- 先読みを 0.12秒 → 0.2秒にして、画面の処理で一瞬止まっても音が遅れにくくした。

## 3D合奏（2026年10月）

「🎭 3D合奏」タブで、奏者たちが楽器を叩くようすを3Dで見られます（参考：雅楽シミュレーター「越天楽」の作り方）。

- ジャワの曲：屋根つきの東屋（プンドポ）。黒い上着（ブスカップ）・バティックの腰布（パラン模様）・頭の布（ブランコン）の奏者15人が、ござの上であぐらで演奏。
- バリの曲：朱塗りと金の楽器台、白い上着と頭の布（ウドゥン）の奏者12人。背景に割れ門（チャンディ・ブンタル）。
- 音と同時にバチが鍵盤・壺型ゴング・ゴングに当たり、当たった鍵盤が光る。サロン類は左手で前の音を押さえて止める。遠い鍵盤には上半身を傾けて手をのばす。
- 奏者や名札をタップすると休ませる・戻すができる。カメラは 正面・真上・横・近く、指で回す・拡大もできる。
- 「自分も合奏に入る」で楽器を選ぶと、その奏者のかわりに自分が叩ける（ほかは自動）。
- Three.js（r128）は3D合奏タブを開いたときだけ読み込む。動かない部品はまとめて描く回数を減らし、重い端末では画質を自動で下げる。
