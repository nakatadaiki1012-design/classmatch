# 🪘 インド古典音楽 演奏シミュレーター（タブラー＆シタール）

ブラウザで開くだけで使える、**叩いて・聴いて・理論がわかる**学習用シミュレーター。
音はアプリに同梱した本物のタブラーの録音（CC0）で鳴ります（シタールなどは楽器の物理的な特徴をもとにブラウザ内で合成）。

| ファイル | 内容 |
|---|---|
| `index.html` | **タブラー＆バーヤーン演奏シミュレーター**（メイン） |
| `sitar.html` | **シタール演奏シミュレーター**（おまけ） |
| `audio.js` | 2つのページで共有するサウンドエンジン |
| `lessons.js` | タブラーのレッスン・採点練習・耳トレ |
| `samples.js` | 録音を使う仕組み（標準音源の読み込み・自分の録音の登録） |
| `samples-data.js` | 標準音源（本物のタブラーの録音、CC0） |

> すべてのファイルは**同じフォルダに置いたまま**開いてください（`audio.js` を読み込むため）。

## 🪘 タブラー（`index.html`）

### 🎙 音源（本物の録音）
標準の音は **本物のタブラーの録音**（[mmiron「tabla bols」](https://freesound.org/people/mmiron/packs/8162/)、Creative Commons 0）を同梱して使っています（`samples-data.js`）。
選んだ調に合わせて右の太鼓の音程を自動調整し、同じ太鼓を続けて叩くと前の響きが止まる動きも再現。

さらに自分の録音に差し替えることもできます。「叩いてみる」タブの **本物の録音を使う** から、タブラーの録音ファイル（1打ずつ）を
打ち方ごとに登録すると、すべての機能がその音で鳴ります（ダーなどの組み合わせは自動合成、ラ・ゲー↑は無くても代用）。
ファイル名に na / tin / tun / te / ge / ke などが入っていれば一括で自動振り分け。録音はブラウザ内（IndexedDB）に保存され、外部には送信されません。
無料の録音は Freesound（CC0ライセンス）などで入手できます。

### 初心者向け学習機能
- **📚 レッスン**：全20レッスンのコース（音を知る → ティーンタール → 作品）。説明 → お手本 → 採点つき練習 → ★で合格。進み具合は端末に保存。
- **🎯 練習（採点）**：キーボード／タッチで叩くと、**タイミング**と**音の種類（右手・左手が合っているか）**を判定。
  「左手が抜けがち」「遅れ気味」「ティンのところでナーを叩いている」など具体的なアドバイス。機器の遅れの自動補正つき。
  **マイク入力**（タイミングのみ判定）にも対応：机を指で叩いても、本物のタブラーでもOK。
- **👂 耳トレ**：ボル当て（基本・応用）、ターラ当て、リズム聞き取り、目隠しサム当て。答えたあと聴き比べ可能。
- **パダント（唱えて手で数える）**：手拍子（ターリー）／手振り（カーリー）の練習と採点、手拍子音の再生。
- 演奏の流れ：再生速度（40〜100%）、区間のくり返し、各区間をそのまま「叩いて練習」。
- 曲ごとに **📜 伝統的な形 / 🛠 このアプリのオリジナル** を明記。

> ⚠ 手の形・指の使い方など、実際の楽器でしか身につかないことは扱いません。

### できること
- **叩いてみる**：太鼓の絵の場所（縁・中間・中央・バーヤーン）をクリック／タップ、またはキーボードで演奏。
  バーヤーンは押したまま横にドラッグすると、手首で押したように音程が「ウォン↑」と上がります。
- **ボル辞典**：ダー、ディン、ナー、ティン、トゥン、テ、ゲー、ケ…それぞれの打ち方（どの指で・どこを・響かせる／止める）を解説。
- **ターラ（リズム周期）**：ティーンタール、ジャプタール、エークタール、ルーパク、ダードラー、ケヘルワーのテーカを自動演奏。
  サム（X）／ターリー（2,3）／カーリー（0）が円とグリッドで表示されます。テンポや密度（ドゥグン＝2倍など）も変更可。
- **演奏の流れ・自動演奏**：タブラー独奏の一般的な順番を通しで演奏（約3分）。
  テーカ → ペーシュカール → カーイダ（主題と変奏）→ レーラ（高速ロール）→ トゥクラー → チャクラダール・ティハーイー → サムで終演。
  ティハーイー（同じフレーズを3回）は色分けして表示されるので、着地の仕組みが目で見てわかります。
- **レヘラー**（周期を示す伴奏旋律・ハルモニウム）と**タンプーラ**（持続音）も鳴らせます。
- **自分で作る**：`Dha Dhin Dhin Dha | TiRaKiTa DhaGe` のようにボルを書くと演奏します。

## 🎸 シタール（`sitar.html`）

- **弾いてみる**：フレットをクリック／タップで演奏。押したまま**上にドラッグ**するとミーンド（弦を引いて音程を上げる）。
  チカリ弦、Da/Ra（右手の向き）、**共鳴弦**（同じ音名の弦が光って響く）も再現。
- **ラーガ**：ヤマン、バイラヴ、カーフィー、ブーパーリー、マールカウンス、キルワーニー。
  上行・下行・パカド（特徴的なフレーズ）を試聴でき、演奏する時間帯や気分も解説。フレットは選んだラーガに合わせて変わります。
- **演奏の流れ・自動演奏**：アーラープ（拍なし）→ ジョール → ジャーラー →（ここからタブラーも参加）ガット → トーダー＋ティハーイー → ドゥルト・ジャーラーで終演。
- キーボード：`Z`〜`M` 低音域、`A`〜`L` サから上、`Q`〜`P` 高いサから上、`Space` チカリ、`Shift`＋キーで下の音からミーンド。

## 技術メモ
- HTML + CSS + JavaScript のみ。外部ライブラリなし・オフライン動作。
- タブラー：膜の固有振動（モード）を加算合成。ダーヤーンはシャーヒーによる整数倍音、ナーは基音の消音、閉じた音の急速な減衰、
  バーヤーンの音程の沈み込みと手首による音程上昇（ミーンド）をモデル化。打撃ノイズはフィルター処理したノイズで再現。
- シタール／タンプーラ：倍音加算合成。強調される倍音帯域が時間とともに移動する現象として**ジャワーリー（駒のうなり）**を再現。
  ミーンドは再生速度の連続変化で実現。
- 正確なタイミングのため `AudioContext.currentTime` による先読みスケジューリングを使用。
